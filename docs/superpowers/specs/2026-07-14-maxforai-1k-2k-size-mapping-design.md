# Image-2 中转 1K/2K 尺寸映射设计

**日期：** 2026-07-14  
**状态：** 已确认，待实施

## 目标

让 `image-2中转` 只暴露上游真实支持的 `1K`、`2K` 两个分辨率档位，并且固定比例完全通过标准 Images API 的 `size` 字段约束。`4K` 不再作为该模型的可选档位；智能比例继续发送 `size: "auto"`。

## 已确认规则

- 站内模型 ID 保持 `maxforai-image-2-relay`，展示名保持 `image-2中转`，上游模型保持 `gpt-image-2`。
- 支持的分辨率只有 `1K`、`2K`。
- 用户从其他模型携带 `4K` 切换到 `image-2中转` 时，自动降为 `2K`。
- 用户原来选择 `1K` 或 `2K` 时保持原值。
- 智能比例保留；无论当前分辨率档位是什么，都发送 `size: "auto"`。
- 固定比例必须发送明确的 `WIDTHxHEIGHT`，不能依赖 prompt 文本约束画幅。
- 旧页面或直接 API 即使仍提交 `4K`，服务端也按 `2K` 处理，不能把不支持的 4K 尺寸交给上游。
- 其他图片模型的分辨率和比例行为不变。

## 尺寸映射

| 比例 | 1K `size` | 2K `size` |
|---|---:|---:|
| 智能比例 | `auto` | `auto` |
| 1:1 | `1024x1024` | `2048x2048` |
| 16:9 | `1536x864` | `2048x1152` |
| 9:16 | `864x1536` | `1152x2048` |
| 4:3 | `1344x1008` | `2048x1536` |
| 3:4 | `1008x1344` | `1536x2048` |
| 3:2 | `1536x1024` | `2016x1344` |
| 2:3 | `1024x1536` | `1344x2016` |

## 架构与数据流

### 共享模型契约

`src/utils/maxforaiImageModels.mjs` 作为单一真相，公开支持比例、支持分辨率、分辨率归一化和比例到尺寸的映射。现有 `resolveMaxForAiImageSize(aspectRatio, resolution)` 签名保持不变，避免改动所有调用方；内部先把 `4K` 归一到 `2K`，再读取对应映射。

### 界面能力

模型能力声明增加 `supportedResolutions: ['1K', '2K']`。所有使用共享 `getQualityOptionsForModel` 的设置侧栏只显示两档；底部输入栏当前存在硬编码三档，需要改为根据当前模型能力生成选项。

切换模型时执行一次参数归一化：`1K` 保持、`2K` 保持、`4K` 改为 `2K`。即使某个旧入口没有及时更新，服务端 provider 边界仍会再次归一化。

### Provider 请求

文生图和图生图继续复用 `buildMaxForAiImageRequestBody`。固定比例提交映射后的 `size`；智能比例提交 `auto`。编辑端点继续使用 multipart，生成端点继续使用 JSON；响应兼容 URL 和 base64、零自动重试、提交状态不确定保护均保持不变。

## 错误处理与兼容

- 未支持的比例仍返回 `provider_bad_request`，不猜测最接近比例。
- 缺少分辨率时维持现有安全默认 `1K`。
- 旧任务中的 `4K` 不报错，统一降到 `2K`，保证刷新恢复和重试不会因历史参数中断。
- 智能比例的实际宽高由上游决定；验收只要求请求明确为 `size: "auto"` 且返回有效图片，不承诺特定像素或画幅。
- 固定比例验收同时记录请求尺寸和实际文件尺寸；如果上游归一化输出，必须如实报告，不把请求尺寸当作实际像素承诺。

## 测试与发布验收

### 自动化测试

- 共享契约：七个固定比例分别覆盖 1K、2K；智能比例覆盖 `auto`；4K 覆盖自动降到 2K；非法比例覆盖拒绝。
- Provider：文生图 JSON 与图生图 multipart 分别断言正确 `size`，并锁定付费 POST 单次尝试。
- 能力与界面：`image-2中转` 只返回 1K/2K，切换时 4K 归一为 2K；GPT Image 2、Nano Banana 等其他模型仍保留原档位。
- 全量运行 `npm run verify`，确保测试、lint、构建和工程门禁通过。

### 云上真实验证

发布后通过梅奥 `/api/jobs` 真实提交三张：

1. 智能比例：确认请求 `size: "auto"`，图片有效。
2. 固定比例 1K：确认使用 1K 映射尺寸，图片有效并记录真实宽高。
3. 固定比例 2K：确认使用 2K 映射尺寸，图片有效并记录真实宽高。

每个任务必须确认 `provider=maxforai`、`providerModel=gpt-image-2`、attempt 为 1、`retryCount=0`、没有 fallback、结果 URL 可读取。若出现 `provider_submission_unknown`，立即停止后续付费测试，避免重复付费。

## 不在本次范围

- 不恢复 4K。
- 不调整价格或旧积分计算。
- 不为上游输出增加二次裁剪、拉伸或放大。
- 不改变其他图片渠道的模型、比例或分辨率。
