# 图片升级滑动对比查看器设计

**日期：** 2026-07-16  
**目标环境：** 本地开发环境  
**范围：** 图片升级下的原图精修、白底精修、产品还原

## 目标

让用户在每组图片升级结果中点击已完成图片，进入大图滑动对比查看器，通过同画布遮罩直观看到原图与升级结果的差异，并在同一项目组内连续切换结果。

## 非目标

- 不修改图片生成、分析、计费、任务队列或后端接口。
- 不改变翻译、万物替换、买家秀、视频等其他模块的预览行为。
- 不为历史结果补造缺失的原图地址。
- 不做像素差异分析、自动评分或图像配准。

## 功能范围

对 `module=retouch` 且 `subFeature` 为以下值的项目启用：

- `original`：原图精修
- `white_bg`：白底精修
- `product_restore`：产品还原

只有存在结果图的已完成项进入对比组。每项使用：

- 原图：优先 `sourcePreviewUrl`，否则 `sourceUrl`
- 升级结果：`imageUrl`
- 标题：优先 `fileName`，否则按项目名和组内序号生成

原图精修和白底精修的工作流已经返回 `sourceUrl`；产品还原也按目标素材逐项保存 `sourceUrl`。查看器只消费这些既有字段，不新增持久化状态。

## 交互设计

### 入口

- 图片升级的已完成结果卡图片区域可以点击。
- 有原图与结果图时，悬浮卡片显示“滑动对比”。
- 缺少原图但存在结果图时，入口仍可点击，文案为“放大查看”。

### 对比画布

- 原图位于底层，升级结果位于上层，上层按水平百分比裁剪。
- 初始分割位置为 50%。
- 鼠标在画布内移动时，分割线实时跟随横向位置。
- 鼠标按住拖动、触控拖动和触控笔拖动均使用 Pointer Events。
- 鼠标移出画布后保留最后位置。
- 切换当前图片后，分割位置恢复到 50%。
- 分割位置限制在 0% 到 100%，避免指针越界制造无效样式。
- 左右固定标注“原图”和“升级后”，分割线上提供可见手柄。

### 比例处理

两张图片都使用 `object-contain`，不拉伸、不裁切。画布以可用视口为约束，图片按各自真实比例完整展示。如果前后比例不同，显示“前后比例不同”提示，明确这不是像素级配准对比。

### 组内浏览

- 查看器顶部显示子功能、文件名与 `当前序号 / 总数`。
- 左右按钮切换同一项目内的已完成结果。
- 查看器普通区域响应 `ArrowLeft` / `ArrowRight` 切换图片。
- `Escape` 关闭查看器。
- 分割手柄可聚焦；手柄聚焦时方向键每次微调 2%，并阻止事件继续触发组内切换。
- 查看器支持下载当前升级结果。

## 组件边界

新增专用组件 `src/shell/components/RetouchComparisonViewer.tsx`，避免把遮罩交互混入承载普通图片和视频的 `ImageLightbox`。

组件输入：

```ts
export interface RetouchComparisonItem {
  id: string;
  originalUrl?: string;
  resultUrl: string;
  title: string;
  subFeatureLabel: string;
  originalWidth?: number;
  originalHeight?: number;
}

interface RetouchComparisonViewerProps {
  open: boolean;
  items: RetouchComparisonItem[];
  currentIndex: number;
  onIndexChange: (index: number) => void;
  onClose: () => void;
  onDownloadCurrent?: () => void;
}
```

新增纯逻辑文件 `src/shell/components/retouchComparison.ts`，负责：

- 判断项目是否属于支持范围。
- 把 `GeneratedResult[]` 映射为稳定顺序的对比项。
- 根据 Pointer Event 的 `clientX` 和画布边界计算 0–100 的分割百分比。
- 判断原图与结果图比例是否不同；结果图自然尺寸在组件加载后读取，不持久化。

`ProjectCard` 只负责：

- 为支持范围构建对比组。
- 点击结果时按结果 ID 打开正确索引。
- 缺少原图时回退到现有普通 `ImageLightbox` 并显示提示。
- 复用现有单图下载函数。

## 状态与错误处理

- `open`、当前索引和分割百分比均为前端临时状态，不写入用户状态。
- 切换项目或结果被删除后，当前索引夹紧到有效范围；无可用项时自动不渲染。
- 原图地址缺失：回退普通大图预览，并提示“原图缺失，暂无法对比”。
- 原图加载失败：对比查看器保留结果图，画布显示原图加载失败提示。
- 结果图加载失败：保留弹窗与导航，显示结果加载失败提示，用户仍可切换下一张或关闭。
- 只渲染当前一对图片，不同时加载整组大图。

## 测试与验收

### 自动化测试

- 支持范围只包含图片升级的三个子功能。
- 对比项只包含已完成且有 `imageUrl` 的结果，并按项目结果顺序输出。
- 原图优先级为 `sourcePreviewUrl` 高于 `sourceUrl`。
- 指针位置正确换算并夹紧到 0–100。
- `ProjectCard` 对有原图的图片升级结果路由到专用查看器，对缺原图结果回退普通灯箱。
- 查看器支持关闭、组内切换、下载、分割线复位和键盘手柄微调。

### 本地验收

1. 运行相关定向测试。
2. 运行 `npm run build`。
3. 运行 `npm run doctor` 并确认本地服务健康。
4. 在 `http://127.0.0.1:3000/` 使用真实持久化项目验证：
   - 点击已完成结果打开对比查看器；
   - 鼠标移动、拖动和触屏语义下分割线可控；
   - 左右切换同组结果并恢复 50%；
   - 关闭、下载和刷新后再次打开正常；
   - 缺原图的历史项不会白屏或报错。

## 完成标准

- 三个图片升级子功能统一获得滑动遮罩对比能力。
- 不改变任务创建、生成结果或持久化合同。
- 其他模块继续使用原预览路径。
- 自动化测试、构建、doctor 与本地浏览器真实验收均通过。
