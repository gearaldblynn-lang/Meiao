# 图片升级对比查看器缩放设计

## 目标

在现有前后遮罩对比查看器中增加同步缩放和平移，让用户能放大检查产品纹理、结构和文字细节，同时继续用鼠标移动遮罩比较原图与升级结果。

## 交互合同

- 原图与升级结果始终共享同一组缩放和平移参数，避免比较位置错位。
- 缩放范围为 100%–400%，工具栏提供缩小、当前倍率、放大和复位图标；画布滚轮围绕鼠标位置缩放。
- 100% 时保留现有行为：鼠标移动或拖动调整遮罩。
- 放大后，鼠标悬浮移动继续调整遮罩；按下拖动画面用于平移。按住空格拖动同样进入平移。
- 双击画布或点击复位图标回到 100%、居中和 50% 遮罩。
- 切换图片或重新打开查看器时，缩放、平移和遮罩都复位。
- 平移被限制在按当前倍率计算出的画布边界内，缩回 100% 时自动回到中心。

## 渲染与状态

- 两张图片仍分别位于原图层和结果裁切层中；给两张图片应用相同的 `translate3d + scale`，遮罩裁切和分割线保持在画布坐标系。
- 缩放、平移、空格键和指针交互状态仅存在于查看器组件内，不写入项目持久化状态。
- 结果比例与原图不同时继续使用 `object-contain`，并保留现有比例差异提示。

## 边界与可访问性

- 缩放按钮有 `aria-label`、悬浮提示、禁用边界状态和可见百分比。
- 滚轮事件只在查看器画布内阻止页面滚动。
- 方向键切图、遮罩滑块键盘操作、Esc 关闭和下载能力保持不变。
- 触屏可使用缩放按钮；放大后单指拖动平移。遮罩仍可通过鼠标悬浮或键盘滑块精调。

## 验证

- 纯函数测试覆盖倍率限制、围绕指针缩放、平移限制和缩回 100% 复位。
- 组件契约测试覆盖同步 transform、滚轮、缩放控件、平移和复位。
- 本地构建与 doctor 通过后，在已有产品还原结果上真实验证：打开、放大、平移、滑动遮罩、复位、切图和刷新。
